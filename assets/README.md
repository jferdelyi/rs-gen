# assets

Images of the project.

| File | Role |
|---|---|
| `rs-gen-icon.svg` | The icon: a shell prompt `>_` drawn as a Markov chain. Logo of this README and of the `rs-gen-core` docs. |
| `rs-gen-icon-1024.png` | The icon as a 1024 px PNG, for the places that do not take SVG. |
| `social-preview.png` | Image shown when the repository link is shared. GitHub does not read it from the repository: upload it in *Settings › General › Social preview*. |

The web front keeps its own copies of the icon in [simple-web-front](../simple-web-front/README.md), since only that directory is served.
